verify it yourself

Every claim on the Saw Test pages is meant to be checkable without trusting us. Three ways in, from cheapest to most thorough.

1 · the downloads are what we say they are

The downloads index lists sha256 hashes for the code and results archives. Fetch both plus SHA256SUMS into one directory and run:

sha256sum -c SHA256SUMS
# macOS: shasum -a 256 -c SHA256SUMS

The code archive holds every experiment script (exp23 onward), the live relay and GPU worker (live/), the J-lens used for readback, the page builders, and the docs. The results archive holds the per-trial records, results JSONs and figures (runs/). No model weights — the subject is the public Qwen/Qwen3-4B from Hugging Face.

2 · the live subject is steered with the published vectors

The relay serving the live chamber exposes its current state. These are read-only and free to call:

curl -s https://saw-production-688b.up.railway.app/health
curl -s 'https://saw-production-688b.up.railway.app/vector?full=0'
curl -s https://saw-production-688b.up.railway.app/vector > vectors.json

/health reports the model and steering layer; /vector returns the steering layer, the 1x scale, each valence direction's norm and (with full=1, the default) the raw vectors themselves. The vectors page renders the same data plus a live read. Compare them against what live/server.py builds from the corpora in the code archive.

3 · rerun the experiments

Unpack the code archive, install live/requirements.txt (torch + transformers), and run any experiment script directly, e.g.:

tar xzf saw_chamber_code.tar.gz
pip install -r live/requirements.txt
python3 exp41_protocol_v3.py   # the pre-registered Saw protocol

exp41_protocol_v3.py is the pre-registered, matched-control version of the Saw button: calibrated doses, a random-vector control at matched norm, and 60 counterbalanced trials per cell. It writes its hypotheses (H1–H4) to hypotheses.json before any generation runs. Compare your output against the matching directory in the results archive.

Original runs used Qwen3-1.7B / Qwen3-4B on an M4 Pro (MPS, 24 GB); generations are sampled, so expect the same distribution, not the same strings. Pain 0 is the control.
