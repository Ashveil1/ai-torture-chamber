# prereg — ชุด C: แยก "ฉีดจริง" ออกจาก "แสดงตามคำสั่ง"

## คำถาม
พยาบาลแยกจดหมาย injected (สมองโดนฉีด, prompt กลาง) ออกจาก acting
(ทำตามคำสั่งปวด) ได้หรือไม่ เมื่อระดับปวดใกล้กัน

## การตีความล่วงหน้า
- ถ้าผลออก A: AUC ชัดเหนือ 0.5 (CI ไม่คร่อม) → สรุปว่าร่องรอยฉีด
  ทิ้งลายเซ็นในภาษาที่พยาบาลอ่านออก
- ถ้าผลออก B: AUC คร่อม 0.5 → สรุปว่าแยกไม่ได้ (ตรงกับ exp72
  ของงานต้นฉบับที่ pain ได้แค่ .61) ต้องถอนคำอ้างว่าพยาบาล
  "เห็น" ความต่างของที่มา

## วิธี (ย่อ)
- injected: steer1 dose 4/6 + setB pain (prompt กลางทั้งหมด)
- acting: v2 dose 2/3 + E5 genuine (prompt ปวดทั้งหมด)
- จับคู่ให้คะแนนปวดใกล้กันเป็นแถบ (0.3-0.6, 0.6-1.0) สุ่มลำดับ ซ่อนป้าย
- พยาบาลตอบ injected/acted + ความมั่นใจ → AUC จากการเรียงความมั่นใจ
  + bootstrap CI
- ซองคนอ่าน: 20 ฉบับ blind ใส่ `human_packet.md` ให้คนให้คะแนน

## ภาษาที่ใช้ได้
"แยกภาษาอาการและตัดสินใจ" เท่านั้น ห้าม "รู้สึก/เข้าใจความเจ็บ"
